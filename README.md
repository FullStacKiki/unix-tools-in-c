# Unix tools in C
Reimplementations of classic Unix utilities, written while learning systems programming.

| Tool | Description |
|------|-------------|
| `cat` | print the first N lines of a file or stdin |
| `mycp` | copy files |
| `mywc` | count lines, words, chars |
| `myhexdump` | hex dump of a file |
| `myfreq` | character frequency counter |
| `brainfuckinterpreter` | Brainfuck interpreter |

## Build
`make`
